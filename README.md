## Overview

This work studies how to deliver the current version of a high-definition (HD) map object before it expires when vehicles have short, intermittent contacts with roadside units (RSUs). The approach places complementary coded shards along predicted vehicle routes and uses rank-aware requests to obtain the independent shards needed for decoding.

## Planned Release

- Simulation code for coded placement, rank-aware recovery, and the evaluated baselines.
- Trace selection and preprocessing scripts, experiment configurations, and random seeds.
- Experimental results and scripts for reproducing the paper's figures and tables.

## Trajectory Datasets

The evaluation uses Porto taxi trajectories and highD highway trajectories. The original traces are available from their respective dataset providers. The release will document the trace selection and preprocessing steps used in the experiments.
